## Installation & Usage
###### Requirements 
- Node.js
- npm or yarn
###### Installation Steps 
1. Clone the project 
```bash
git clone https://github.com/Kaveh-Khorshidi/Coffee-Shop.git
```
2. Move into the project directory
```bash
cd Coffee-Shop
```
3. Install dependencies
```bash
npm install
```
###### Usage Steps
Start the development server
```bash
npm run dev
```
